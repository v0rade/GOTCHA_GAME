# Gotcha Game - Virtual Pet Simulation

🎮 **Live Demo:** [https://gotcha-two.vercel.app/](https://gotcha-two.vercel.app/)

---

## 📖 Deskripsi Proyek
**Gotcha Game** adalah aplikasi web simulasi hewan peliharaan virtual (*virtual pet*) interaktif berbasis browser yang terinspirasi dari konsep klasik Tamagotchi. Pemain dapat memilih karakter dan merawat hewan peliharaan mereka dengan menjaga indikator kebutuhan tetap seimbang agar karakter tetap sehat dan bahagia.

---

## ✨ Fitur Utama
- **Pemilihan Karakter:** Pilih berbagai karakter unik sebelum memulai permainan.
- **Indikator Status Real-time:**
  - 🍖 **Food:** Menjaga tingkat kekenyangan karakter.
  - ❤️ **Health:** Menjaga kondisi kesehatan karakter.
  - 💤 **Sleep:** Waktu istirahat dan tidur untuk memulihkan energi.
  - ⭐ **EXP & Level:** Tingkatkan poin pengalaman karakter saat berinteraksi.
- **Interaksi & Animasi Interaktif:** Aktivitas bermain, makan, dan tidur dengan pergantian latar belakang dinamis.
- **Full Responsive & Web-based:** Dapat dimainkan langsung melalui browser tanpa instalasi tambahan.

---

## 🛠️ Teknologi yang Digunakan
- **HTML5:** Struktur halaman dan layout game.
- **CSS3:** Styling custom, tata letak animasi, dan tema visual.
- **JavaScript (Vanilla):** Logika game, status indikator, timer, dan manipulasi DOM.
- **Bootstrap:** Komponen antarmuka responsif.
- **Vercel:** Hosting dan deployment live demo.
